## Urkon workflow

This repository is driven by [urkon](https://github.com/ardanlabs/urkon): issues and
labels dispatch a coding agent through the BMAD loop (`bmad:*` labels).

- [`.urkon/workflow.md`](.urkon/workflow.md) — the loop, the labels, and who may set which.
- [`.urkon/mechanics.md`](.urkon/mechanics.md) — sandboxing, retries, identities, PR conventions, hard limits.
- [`.urkon/agent-policy.md`](.urkon/agent-policy.md) — the rules the dispatched agent follows.

If you are an agent working an issue in this repository, read all three before acting.
